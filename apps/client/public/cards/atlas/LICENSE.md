# Атласная колода — происхождение и лицензия

## Лицензия

**CC0 1.0 Universal (Public Domain Dedication)** — общественное достояние.
Коммерческое использование разрешено, атрибуция не требуется.

Проверено через Wikimedia Commons API (`prop=imageinfo&iiprop=extmetadata`):

```json
"LicenseShortName": { "value": "CC0" }
"UsageTerms": { "value": "Creative Commons Zero, Public Domain Dedication" }
```

## Почему это законно

Оригинальный дизайн 1862 года — общественное достояние: Шарлемань умер в 1901,
срок охраны в России истёк в 1972, в США колода в PD как опубликованная до 1930.

Фомин перерисовал колоду **как оригинальные векторы** («own work») и передал
в CC0. Это важно: сканы современных розничных колод использовать нельзя —
советские перерисовки охраняются отдельно. В частности, версия «Русского стиля»
Юрия Иванова (ум. 2019) под охраной **до 2089 года**.

Прецедент использования: игра [OpenFool](https://github.com/trolley813/OpenFool)
(MIT) поставляет эту же колоду.

## Состав

36 карт для дурака (6–туз, четыре масти) + 2 рубашки.
Файлы `<ранг>_<масть>.svg`, viewBox `0 0 360 540` (соотношение 2:3).
Оптимизированы SVGO (`--multipass -p 2`).

## Важно

Использовать **арт** можно свободно. Названия «Русский стиль» и «Атласные»
как **бренд** — только после проверки товарных знаков по классу 28 МКТУ
(статус в Роспатенте не проверялся).
