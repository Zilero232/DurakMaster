# Translations — i18next

Part of the [style guide](../README.md).

## 18. Translations — i18next

`react-i18next`, one namespace (`translation`), the key is passed whole:

```tsx
const { t } = useTranslation();

<Text>{t('table.take')}</Text>;
```

- **No `useTranslation('namespace')`** — there is one namespace in the project, the prefix is part of the key.
- **Locales are split by area, merged into that one namespace.** `apps/mobile/shared/i18n/locales/{ru,en}/` holds one JSON file per area (`auth`, `common`, `errors`, `lobby`, `profile`, `rules`, `settings`, `social`, `table`), each with its area as the top-level key (`{ "auth": { … } }`); the language's `index.ts` spreads them into one object.
- **Keys are typed** from the Russian locale through the `CustomTypeOptions` augmentation in `apps/mobile/i18next.d.ts`: a typo in a key is a compile error rather than a raw identifier on screen. The Russian files are the source of truth; the English ones may lag behind.
- **Interpolation — double braces**: `t('result.rating', { value: ratingDelta })` for `"rating": "Рейтинг +{{value}}"`.
- **Pluralization — key suffixes**, not ICU syntax. The forms are computed by `Intl.PluralRules`:

  ```jsonc
  // ru — three forms
  { "cards": { "count_one": "{{count}} карта", "count_few": "{{count}} карты", "count_many": "{{count}} карт" } }

  // en — two
  { "cards": { "count_one": "{{count}} card", "count_other": "{{count}} cards" } }
  ```

  ```tsx
  <Text>{t('cards.count', { count: hand.length })}</Text>
  ```

- A key added only to the `ru` file will pass the types, but in English the screen will show the identifier — edit both languages in one commit.
- **i18next is initialised synchronously** (`initAsync: false` in `shared/i18n/model/i18n.ts`): the resources are bundled, and i18next v26 defaults to an async init that suspends the first render ([pitfalls](../../architecture/pitfalls.md)).
- The stored language is restored by `restoreLocale` in `views/root-layout` (`model/hooks/use-app-bootstrap`). The splash screen stays up until it, the fonts and the settings store are ready, so the first frame is already in the right language. To change it — `changeLocale(locale)`; the choice survives a restart.
- A key assembled in a config is typed with `ParseKeys` from `i18next` (`AppShell.config.ts`, `SettingsPanel.config.ts`) — `shared/i18n` also exports it as `TranslationKey` — not `string`.
